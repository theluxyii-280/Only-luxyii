# 🩶 Sobre mim

Sou **only luxyii**, desenvolvedor focado em construir projetos envolvendo **Inteligência Artificial, Agents, sistemas, Android, backend e infraestrutura**.

Tenho preferência por projetos grandes, arquiteturas separadas e tecnologias escolhidas pelo que fazem melhor, em vez de colocar linguagens diferentes apenas para aumentar a lista do projeto.

Atualmente meu principal foco está na **Lysie AI**, uma plataforma de Inteligência Artificial e Agents em desenvolvimento com modelos próprios, execução local controlada, ferramentas, segurança, privacidade ao usuário e arquitetura distribuída.

> **Foco atual:** AI/ML, Agents, Systems Programming, runtimes locais, infraestrutura distribuída e Android.

# 💎 Projetos em desenvolvimento

## 🔗 Lysie

Plataforma de **Inteligência Artificial e Agents** projetada para crescer sem depender completamente de um único provedor, modelo ou servidor.

### Direção técnica

```text
Python
└── IA, treinamento, inference, RAG, datasets e avaliação

Rust
└── políticas, permissões, sandbox, segurança e runtime crítico

Go
└── APIs, gateways, streaming, workers e serviços concorrentes

C / C++
└── inference, kernels, otimizações e componentes nativos

TypeScript
└── painel web, interfaces e ferramentas complementares
```

### Objetivos

- Modelos próprios da família **Lysie**.
- Agent com execução local controlada.
- Sandbox isolado do sistema/servidor interno.
- Ferramentas de programação, pesquisa e projetos.
- Runtime local para tarefas pesadas.
- Infraestrutura distribuída.
- Memória e conhecimento controlados.
- Privacidade por design.
- Painel para acompanhar, interromper e corrigir tarefas.
- Suporte futuro para Android, Desktop e servidores próprios.
